# my-first-linux-project
My First Linux Bash Backup Project
This is a beginner-friendly project to help you learn how to write and run a simple Bash script on Linux. The script will back up a folder of your choice to a compressed archive with a timestamp in the name.

Project Structure
my-bash-backup/
├── backup_script.sh      # The main Bash script
├── README.md            # This file
└── (optional) test_data/ # Your folder to back up
